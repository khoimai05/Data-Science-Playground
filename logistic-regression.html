How logistic regression works

We model P(class=1) with the sigmoid: σ(z) = 1/(1+e⁻ᶻ) where z = w₁x + w₂y + b. The decision boundary is the line where P = 0.5, i.e. z = 0.

We minimize binary cross-entropy: -Σ [y log(p) + (1-y) log(1-p)]. Gradient descent updates the weights so the boundary separates the two classes.

Unlike linear regression, there's no closed-form solution—we rely on iterative optimization to find the best boundary.
