support vector machine

find the maximum-margin decision boundary

How it works

SVM finds the hyperplane that separates two classes with the largest margin. The margin is the distance between the boundary and the nearest points — the support vectors.

A higher C penalizes misclassification more, producing a tighter fit. A lower C allows a wider margin at the cost of some errors.

The model minimizes ½‖w‖² + C·Σ hinge(yᵢ, fᵢ) using sub-gradient descent.
